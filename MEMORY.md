# Public project notes
CreatorHub KK is independently maintained. All distribution and update links point to ichxjz/CreatorHub-KK-. See NOTICE.md for source provenance. Never include local account data in releases.

Windows 0.4.2 uses the same app/web and insight engine as the modified workbench. Startup automatically opens the owned service in a native WebView2 window; service management and updates stay in a separate window with no control bridge exposed to the workbench. --no-autostart opens management only. Downloads and the existing KK user-data directory are retained. Canonical distribution now uses ichxjz/CreatorHub-KK-.
